# Easy Returns

## RETURNS & EXCHANGES



#### An Overview

For eligible items Jewelclues accept return packages postmarked within 30 days from the delivery date. If your return is postmarked after this time frame, your return will be denied and sent back to you or disposed off at the will of Jewelclues.

We accept exchanges for eligible items within 30 days of the item’s delivery date. Items initiated for exchange must be postmarked for return within 7 days of initiation. If the item you are exchanging is not postmarked within 7 days, you will be automatically charged for the cost of the new item.

Dressed marked as Made-To-Order on our website can not be exchanged. Personalized / Custom Size / Customized dresses are considered final sale and not eligible for return and refund.

All refunds are processed as per Refund Policy. If a discount code or promo code is applied while placing the order, Promo Terms will also apply.

Jewelclues issue return label for Contiguous United States addresses only. If you need to make a return from outside of Contiguous United States, you are responsible for return shipping.
