## Introducing a more honest way to find coupon codes

### Every code has a history, and we track it

Codes fail for boring reasons: they expire, they only cover one category, they only apply to a first order. Calling any of them "verified" would be a guess dressed up as a fact. We publish the chance instead, built from checkout data and shopper answers, and we track it over time.
